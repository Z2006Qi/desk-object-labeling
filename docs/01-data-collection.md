# 第一轮数据采集

## 检测类别

本实验选择两类桌面物体：

```text
0: mouse
1: keyboard
```

## 采集方式

第一轮训练图片为自行拍摄。拍摄时改变物体角度、距离、摆放位置和桌面背景，尽量让模型看到同一类物体在不同状态下的外观。

原始图片分批保存在鼠标和键盘目录中。`raw_new_mouse` 与 `raw_new_keyboard_batch2` 属于补拍批次，其中部分图片后来已合并到对应类别目录，因此统计时不能把所有文件夹数量直接相加。

## 第一轮数据数量

去除重复图片后，第一轮共整理209张原始图片：

| 类别 | 图片数量 |
| --- | ---: |
| mouse | 153 |
| keyboard | 56 |
| 合计 | 209 |

第一轮数据没有专门加入“画面中完全不存在鼠标和键盘”的背景负样本。

## 文件管理

- 每张图片使用唯一文件名；
- 原始图片单独保留，标注时不覆盖原图；
- 补拍批次合并前检查重复文件；
- 训练集、验证集和测试集划分前再次检查重复图片，避免相同图片进入不同集合。
