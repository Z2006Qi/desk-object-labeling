# 第一轮Jetson测试

## 测试目的

将第一轮训练得到的 `best.pt` 部署到Jetson，连接USB摄像头进行实时检测，确认模型能否识别mouse和keyboard，并观察实时检测速度。

第一版检测程序使用 `jetson_detector.py`，实时显示：

- 目标类别；
- 检测框；
- 置信度；
- FPS。

## 测试方法

```bash
python3 jetson_detector.py --model best.pt --source 0
```

在摄像头画面中分别放置鼠标和键盘，并改变物体的位置、方向、距离和背景，观察检测框及类别是否稳定。

## 第一轮发现的问题

第一轮训练数据中的鼠标外观和颜色不够丰富，其中蓝色鼠标样本占据了明显特征。实际测试时，模型容易把其他蓝色物体识别成mouse。

这说明模型没有充分学习鼠标的形状特征，而是对颜色等表面特征产生了依赖，第一轮模型存在过拟合和泛化能力不足的问题。

## 第一轮结论

第一版模型能够完成mouse和keyboard的基本实时检测，但样本多样性不足，暂时不满足稳定验收要求。下一步需要补充不同颜色、外形、角度和背景的鼠标与键盘图片，并重新标注和训练。
