# 最终阶段：数据集扩充与复核至 1055 张

## 最终数据集

在 580 张版本之后继续补充和复核数据，最终形成 `dataset_1055`。类别编号保持不变：

```text
0: mouse
1: keyboard
```

最终数据集包含：

| 项目 | 数量 |
| --- | ---: |
| 图片 | 1055 |
| 标签文件 | 1055 |
| 空标签负样本 | 54 |
| mouse 标注框 | 748 |
| keyboard 标注框 | 622 |

空标签文件对应画面中不存在 mouse 或 keyboard 的负样本，不是缺少标注。

## 数据集划分

使用随机种子 42 划分 train、val 和 test：

| 数据集 | 图片 | 标签 | 空标签 |
| --- | ---: | ---: | ---: |
| train | 738 | 738 | 40 |
| val | 211 | 211 | 11 |
| test | 106 | 106 | 3 |
| 合计 | 1055 | 1055 | 54 |

## 完整性检查

最终检查结果为：

- 缺失图片或标签配对：0；
- 非法标签：0；
- train、val、test 文件名交叉：0；
- 跨集合完全相同图片：0；
- 拷贝后 SHA-256 校验通过；
- 旧版本数据集保留，未被覆盖。

`split_manifest.csv` 记录每个文件所属集合及图片、标签哈希；`validation_report.json` 保存完整性检查汇总。

## 最终模型

最终训练成果保存为 `best_1055.pt`，并用于 Jetson 实时检测测试。模型权重与最终数据集通过 GitHub Release `v1.0.0` 提供。
