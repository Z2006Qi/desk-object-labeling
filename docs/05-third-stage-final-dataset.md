# 第三阶段：自行补拍并完成最终数据集

## 第三阶段目的

第二阶段加入网络图片后，数据集累计达到387张。后续测试仍发现模型在实际摄像头画面中存在漏检和误检，因此第三阶段继续由实验者自行拍摄针对性样本。

## 自行补拍

第三阶段新增图片编号为388～580，共193张，全部由实验者自行拍摄：

```text
580 - 387 = 193
```

补拍内容主要针对实际测试中发现的问题：

- 白色鼠标位于画面边缘时经常无法被检测；
- 屏幕容易被误识别为keyboard；
- 一些小物件容易被误识别为mouse；
- 原有数据中的实际桌面背景和困难角度仍不够丰富。

因此新增了白色鼠标位于画面边缘、不同角度和距离的照片，也拍摄了屏幕、小物件及其他容易产生误检的桌面场景。

## 空标签负样本

对于画面中完全没有mouse和keyboard的图片，保留图片并创建同名的空 `.txt` 标签文件。

例如：

```text
images/530.jpg
labels/530.txt
```

其中 `530.txt` 内容为空。空标签用于告诉YOLO该画面中没有需要检测的目标，帮助减少将屏幕误判为keyboard、将小物件误判为mouse的情况。

## 最终数据集

第三阶段补拍图片经过LabelImg人工检查后，与前两个阶段的数据合并，最终形成580张完整数据集。所有数据继续使用固定类别：

```text
0: mouse
1: keyboard
```

完成检查后重新划分train、val和test，最终数据集归档为：

```text
dataset_retrain_580.zip
```

## 最终训练

最终训练使用第二阶段387张训练得到的 `best.pt` 作为基础模型，在580张完整数据集上继续训练。输出单独保存在 `retrain_580` 目录，最终模型用于Jetson检测和实验验收。
