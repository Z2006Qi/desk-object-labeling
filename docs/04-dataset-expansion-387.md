# 第二轮：数据扩充至387张

## 扩充原因

第一轮Jetson测试发现，模型容易把其他蓝色物体识别成mouse。第一轮209张自行拍摄图片在颜色、外形和背景方面不够丰富，因此第二轮从网络补充不同类型的鼠标、键盘和使用场景。

## 网络图片扩充

第二轮分两批加入网络图片：

| 批次 | 目录 | 新增数量 | 累计数量 |
| --- | --- | ---: | ---: |
| 第一批 | `raw_new` | 57 | 266 |
| 第二批 | `raw_new_new` | 121 | 387 |

计算过程：

```text
209 + 57 = 266
266 + 121 = 387
```

本阶段新增的编号210～387均为网络图片。

## 标注和整理

新增图片继续使用相同的YOLO类别编号：

```text
0: mouse
1: keyboard
```

网络图片经过自动预标注和LabelImg人工复核，再与第一轮数据合并。合并时检查文件名和重复图片，避免同一图片重复进入数据集。
完成标注后重新划分train、val和test，形成387张版本的数据集。

## 第二轮训练

第二轮训练使用第一轮得到的 `best.pt` 作为基础模型，在387张数据集上继续训练。训练结果与第一轮模型分开保存，避免覆盖第一轮权重。
